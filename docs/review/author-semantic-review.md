## 需要确认的数学含义

1. **代数正规方程与目标驻点。** 底层规格允许任意矩阵权重和候选 Jacobian。
   `TargetStationary` 仅表示正规右端为零；解释为原目标的一阶驻点还需对称权重及真实
   Jacobian。驻点也不自动是极小值。当前版本保留这些底层代数接口，并明确解释条件。
2. **误差与迭代。** 联合正演/Jacobian 误差界比较相同观测、先验与权重下的模型。
   一步更新界要求近似正规矩阵可逆及显式逆作用界；轨迹收敛另需沿轨迹条件，
   不能由单个目标处的一步界直接推出。状态范数仍为最大绝对分量范数。
3. **正定与奇异先验。** 正定先验因子满足 `Sₐ = L Lᴴ`，白化方向为 `B = L⁻¹ A L`。
   奇异先验使用满列秩矩形因子和支持坐标，结论是特征多项式乘幂、非零实谱及零根重数
   关系。`toNonlinear` 的总函数逆权重映射不对奇异先验保证估计问题等价；本版不提供
   奇异非线性约束求解器。
4. **Physics 与库的用途。** Core 为纯 Lean OEM 数学核心，Physics 为实验数学模块。
   两状态正演含固定偏置，通常是仿射模型。Gaussian 只作中心峰值归一化，正线宽由
   `Valid` 另给；Doppler 正速度降低频率，正性定理不保证一阶近似精度。归一化变量、
   精确实数和合成例子不自动提供现实工程、单位、概率后验或浮点实现保证。

主库继续以可复用的 Lean 数学定义、显式假设和内核检查的定理为目标；外部工程及论文
不进入本版路线。若上述解释与作者原意不符，应先修改规格或发布范围，再决定发布。
